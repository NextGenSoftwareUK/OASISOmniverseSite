THE CORE CAPABILITIES

THE POWER OF THE OASIS API

Six foundational capabilities that reshape how technology integrates and what developers can build.

1. UNIVERSAL CONNECTIVITY
The OASIS API seeks to connect anything to everything — EOSIO, Ethereum, Holochain, SOLID, ActivityPub, IPFS, Telos, SEEDS, ThreeFold and many more. It is unity consciousness expressed within the technical sphere: a network of networks and an abstraction layer over the entire internet.
2. AUTOMATIC LOAD BALANCING & FAILOVER
The system automatically finds the fastest node in your local area regardless of network or platform, delivering the FASTEST possible performance. If any network goes down (Telos, EOSIO, Ethereum, etc.), it auto-switches to the next fastest node in your region with zero downtime.
3. ELIMINATE WEAKNESSES
Like a team of people, different tech has different strengths and weaknesses. By integrating them together as one coordinated system, you eliminate all weaknesses and get the best of all worlds — the whole becomes greater than the sum of the parts.
4. UNIVERSAL SSO & FIELD-LEVEL CONTROL
One login (OASIS Avatar) across every app, website, service and game on every device and platform. You have FULL control of every field of your data — choose per-field whether it's Replicated (Read-Only) or Shared (Read-Write), and who can see it. You choose where your data is stored.
5. INTUITIVE API, ZERO LEARNING CURVE
One intuitive, powerful OASIS API hides lower-level complexities while giving power users full access to deep tech. You never need to learn a new API, language or framework again. When networks upgrade (Holochain RSM, Ethereum 2, etc.), OASIS takes care of the porting for you.
6. NATIVE CODE COMPILATION
The STAR ODK (the heart of OASIS) compiles OAPPs to native code for each platform and provider. For Holochain, it dynamically generates low-level Rust code (DAL) and C# code (BLL), letting you debug in C#, access both Rust and C# libraries, and get the best of both worlds.

// Create a new object
var weapon = new Weapon() { Name = "Dragon Slayer" };
weapon.MetaData["Damage"] = "200";
weapon.MetaData["Rarity"] = "Legendary";

// Save once, HyperDrive replicates everywhere
var result = await STAR.OASISAPI.Data.SaveHolonAsync<Weapon>(weapon);

✓ Saved with ID: {result.Result.Id}
// Same object model across every provider

Search Across All Providers (Query Everything)

// Find all legendary weapons
var legendary = new Dictionary<string, object>
{
    { "Rarity", "Legendary" }
};

var weapons = await STAR.OASISAPI.Data
    .LoadHolonsByMetaDataAsync<Weapon>(legendary);

✓ Found {weapons.Result.Count()} legendary weapons
// Searched across MongoDB, Ethereum, Holochain, IPFS, etc.
